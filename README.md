# GPS Meta campaign · 2027–2028

Public design comparison and downloadable artwork for the Master in Geopolitical Studies at Charles University, Prague.

**Gallery:** https://jalalhussein1982.github.io/gps-meta-campaign-2027-2028/

- Four directions: Bold editorial, Prague after dark, Campus & community, Academic classic.
- Simple and informative Feed posts, each with and without QR, in PNG/JPEG.
- Download package: 32 Feed files, offline comparison, ad copy and alt text.
- Original direction A also includes separate Stories downloads.

GitHub Pages publishes `docs/` from the `main` branch. The site is static HTML/CSS/JavaScript with local fonts and no backend, analytics or external runtime dependencies.

Only publication material is included. Correspondence, original email attachments and internal working notes remain outside this repository. Artwork and brand assets are provided for this campaign; no general reuse licence is granted. Font licences are included under `docs/assets/fonts/`.

The application wording is prepared for the planned 1 November 2026 opening.
